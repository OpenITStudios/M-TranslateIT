## Active Boundary

- **REMOTE_GITHUB only for this development partition:** GitHub `Local` is the source/version-control authority, not an installed Windows, model, or audio runtime. Native driver activation, service provisioning, app packaging, signing and release are outside source-only acceptance.
- **No per-change tests on the user's PC.** Do not request incremental npm/Cargo/Python or hardware tests, dispatch paused CI, create alternative branches, use `main` as fallback, or change the admitted VB-CABLE route during source review.
- **Deferred acceptance:** one integrated local Windows test is reserved for a later explicitly authorized, pinned-SHA build → developer runtime → conditional signed package/install → `TARGET_WINDOWS` acceptance. Until performed, compiler, GPU, microphone, installed app and external receiver evidence remain `UNKNOWN / NOT EXECUTED`.
- GitHub default branch `main` remains reserved for explicitly accepted final outcomes. UserData, personal recordings, exported transcripts, saved actors and private local receipts must never be added to public source.
- Preserve truthful failure/Stop ownership: UNKNOWN is not successful cleanup, native PCM submission is not receiver confirmation, and installed-provider name similarity is not device trust.
